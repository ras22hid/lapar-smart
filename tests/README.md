# Automated tests

One command runs everything, with no human steps and no real credentials:

```bash
pip install -r tests/requirements-test.txt
playwright install chromium        # only if you do not use Microsoft Edge on Windows
python tests/run_all.py            # regression suite + 28 browser test cases
python tests/run_all.py --no-e2e   # regression suite only (no browser needed)
```

The exit code is 0 only when every check passes. Results, screenshots and logs are written to `tests/output/`
(git-ignored): `summary.txt`, `regression.txt`, `e2e.txt`, `results.json` and `shots/`.

| File | What it is |
|---|---|
| `run_all.py` | The runner: starts the app, runs both suites, prints the summary |
| `regression.py` | 138 checks with the Flask test client on a temporary SQLite database |
| `e2e.py` | The 28 functional (FT-01 to FT-14) and regression (RT-01 to RT-14) cases in a real browser (Playwright) |
| `serve_test.py` | Starts the app for the browser tests with its own temporary database |

## Safety

- The tests never use the production database or a real mail account: `TURSO_*`, `GMAIL_*` and `VERCEL` are
  removed from the environment, every database is a temporary SQLite file, and passwords are generated by the tests.
- Gmail is replaced by a stub that records each email (recipient, subject, text) in a file, and `smtplib.SMTP`
  is blocked, so no email can be sent. The tests check the recorded text. Delivery to a real inbox is not tested here.

## Optional settings (`tests/.env.test`, git-ignored, or environment variables)

| Variable | Meaning |
|---|---|
| `LAPAR_TEST_EMAIL` | Address used as the Chief Clerk's email in the tests (recorded, never sent) |
| `LAPAR_BROWSER_CHANNEL` | Playwright browser channel. Default: `msedge` on Windows, bundled Chromium elsewhere |
| `LAPAR_APP_PYTHON` | Python used for the app when it differs from the one that has Playwright |

## Continuous integration

`tests/github-workflow-tests.yml` is a GitHub Actions workflow that runs `python tests/run_all.py` on every push and pull request to `master` and uploads `tests/output/` as an artifact. It needs no secrets. To switch it on, copy it to `.github/workflows/tests.yml` (adding a workflow file needs a GitHub token with the `workflow` scope, or the GitHub web editor).
